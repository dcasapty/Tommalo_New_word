4. **No se despliega ni se lanzan flujos de GitHub ni se crean recursos en Cloudflare** hasta el «sí» del cliente y su

6. Lo que decide el cliente: [PENDIENTES_DEL_CLIENTE.md](PENDIENTES_DEL_CLIENTE.md). Estado: [superpowers/ESTADO.md](superpowers/ESTADO.md).

subir el catálogo, los costos o los contactos · encender pagos, WhatsApp o correo a clientes · cambiar impuestos o precios.
